How to make a Wi-Fi QR code

  1. Enter your network details. The Wi-Fi tab is already open. Type the network name exactly as it appears in your phone's Wi-Fi list, including capital letters and spaces, then the password.
  2. Pick the security type. Choose WPA / WPA2 / WPA3 for almost every modern router. Only choose "No password" if your network is open. If your network doesn't show up in Wi-Fi lists, tick Hidden network.
  3. Make it yours. Pick a pattern and colours, and add your logo if you like. Colours that are too close together for phones to read are blocked for you.
  4. Download and test it. On your phone, forget the network first, then scan the code. If it joins, it's ready to print.

Where to put it

Anywhere guests sit or wait: a reception desk, a table card, the back of a menu, a frame by the door or inside a holiday let's welcome book. Put a short line next to it, like "Scan to join our Wi-Fi", so people know what it does.

Things to know before you print

  • The password is inside the code. Anyone who can see the code can join your network, the same as if they could read the password. For a shop, café or rental, use a separate guest network rather than your main one.
  • Changing your password means a new code. The details are stored in the pattern itself, so if you change the password, make and print a new code.
  • Special characters are handled for you. Network names and passwords with symbols like ; : or " are written in the format phones expect, so you can type them as they are.
What's inside a Wi-Fi QR code?

It's a short piece of text in a standard format that phones recognise, for example WIFI:T:WPA;S:Cafe Guest;P:flatwhite2026;;. T is the security type, S is the network name and P is the password. You can see exactly what your code holds in the line under the preview.

Questions

Wi-Fi QR code questions.

Which phones can join Wi-Fi from a QR code?

Most modern iPhones and Android phones can do it straight from the camera app. Some older Android phones need the "scan QR code" option in their Wi-Fi settings, or a scanner app.

Is my Wi-Fi password sent to QR Origin?

No. Your code is made by your own browser, so the network name and password never leave your device.

The code scans but won't connect. What's wrong?

Usually the network name or password has a small difference, like a capital letter or a space at the end. Check both against your router, and check the security type. Our QR code troubleshooting guide covers the other common causes.

Does the code ever expire?

No. It keeps working for as long as your network name and password stay the same.

How big should I print it?

At least 3 cm wide for a table card scanned at arm's length, and bigger for a sign people scan from further away. The print size guide has a table for different distances.
