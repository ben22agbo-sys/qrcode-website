How to make an email QR code

  1. Enter the address that should receive the emails. The Email tab is already open.
  2. Write a clear subject, like "Booking enquiry" or "Feedback: Oxford store". A specific subject makes these emails easy to find and filter.
  3. Start the message if it helps, like "Hi, I'd like to book a table for". People can edit it before sending.
  4. Style, download and test it on your own phone before printing.

Good uses for an email QR code

  • Feedback cards on tables, receipts or event badges.
  • Enquiries on posters, shop windows and flyers.
  • Support labels on products and packaging.
  • Competitions and sign-ups where people email to enter.
How it works

The code holds a standard email link, for example mailto:hello@example.com?subject=Booking%20enquiry. Phones recognise it and open the default email app. You can see exactly what your code holds in the line under the preview.

Questions

Email QR code questions.

Does scanning the code send an email?

No. It opens a new email with the details filled in. The person reads it, can change it, and chooses whether to send.

What if someone has no email app set up?

Their phone may not know what to open. If many of your customers might be in that situation, a link QR code to a contact form on your website is a good alternative.

Can I change the address after printing?

No. The address, subject and message are stored in the code itself, so changing them means making a new code.
