What size should a QR code be?

The short answer: at least 2 cm wide for something held in the hand, and about a tenth of the scanning distance for anything further away. Here's how to get it right for your print.

Published 20 November 2026

The 10 to 1 rule

A simple rule of thumb that works for most codes: make the code about one tenth as wide as the distance people will scan it from. If people stand 2 metres away, print it about 20 cm wide.

Where it's scannedTypical distanceMinimum width
Business card, label, packagingUp to 20 cm2 cm
Flyer, receipt, table card30 cm3 cm
Menu on the table, counter sign50 cm5 cm
Poster on a wall1 metre10 cm
Shop window, door sign2 metres20 cm
Large banner5 metres50 cm

Treat these as minimums. Going a little bigger costs nothing and helps older phones, dim rooms and people scanning at an angle.

Why the same size doesn't suit every code

A QR code is a grid of small squares called modules. The more information it holds, the more modules it needs. Printed at the same width, a code with more modules has smaller squares, and small squares are harder for a camera to pick out.

In the QR Origin generator, the Grid number under your code shows how many modules wide it is. Some real examples:

What the code holdsWithout logoWith logo
A short link, like https://example.com/menu25 × 2529 × 29
A long tracking link, about 80 characters37 × 3749 × 49

The long link with a logo has almost twice as many modules across, so each square is about half the size at the same print width. If your grid is above about 40 × 40, print bigger than the table suggests, or shorten the link.

Other things that affect scanning

  • The quiet zone. Every code needs a clear border around it, 4 modules wide. It's included in QR Origin downloads, so don't crop it off or place the code right against other graphics.
  • Contrast. A dark code on a light background is easiest to read. Pale colours on white or dark codes on dark backgrounds need a bigger print, or won't scan at all.
  • Print quality. Use the SVG download for print, so edges stay sharp at any size. Stretching a small PNG makes the edges blurry.
  • The surface. Glossy paper, glass and curved surfaces like bottles reflect light and bend the pattern. Go bigger and test in place.

How small can a QR code be?

For close-up scanning, around 2 cm wide is a practical minimum for a short link. Codes on tiny labels can work smaller, but only with very short content and a sharp print. Whatever the size, test the printed code with a few different phones before printing a large batch.

Quick checklist before you print

Width is at least a tenth of the scanning distance. The grid is as small as possible, using a short link. The quiet zone is intact. You've scanned a real test print with two or three phones from the distance people will use.
