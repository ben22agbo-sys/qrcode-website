QR code not scanning? Here's how to fix it.

Most QR codes that won't scan have one of a handful of problems, and nearly all of them are quick to fix. Work through this list from the top.

Published 20 November 2026

1. It's too small for the distance

A code that scans fine on your desk can fail on a wall across the room. Aim for a width of about a tenth of the scanning distance, so 20 cm for a sign read from 2 metres.

Fix: print it bigger. The print size guide has a table for common uses.

2. The colours are too close together

Cameras read the difference between dark and light. Pale grey on white, navy on black or red on orange can all be too close to tell apart, especially in dim light.

Fix: use a dark code on a light background. QR Origin blocks colour pairs below a 3 to 1 contrast ratio, so codes made here are always far enough apart.

3. The colours are flipped

A light code on a dark background looks striking, but not every scanner app handles it, and some older phones struggle.

Fix: keep the code darker than its background if it needs to work for everyone.

4. The border has been cropped or covered

Every QR code needs a clear margin around it, called the quiet zone, 4 modules wide. Scanners use it to find where the code starts. Cropping it off, or placing the code right against text, photos or a pattern, can stop it reading.

Fix: keep the margin from the download, and leave clear space around the code in your design.

5. The logo is too big

A logo covers part of the code, and the code relies on spare data to fill the gap. Too large a logo covers more than it can rebuild.

Fix: keep logos at 25% of the code's width or less, with error correction set to High. QR Origin does both for you. See QR code with logo for our test results.

6. It holds too much information

Long links with tracking tags make dense codes with tiny squares, which are harder to read when printed small.

Fix: use a shorter link, such as a simple page address without the tracking tags. The Grid number under your code in the generator shows how dense it is. Smaller is easier to scan.

7. The print is blurry or stretched

Enlarging a small PNG makes the edges soft, and stretching a code out of its square shape distorts it.

Fix: use the SVG download for print, which stays sharp at any size, and always resize it with its proportions locked.

8. Glare, curves or bad lighting

Glossy lamination, glass, metal and curved surfaces like bottles reflect light or bend the pattern. Dim rooms make everything harder.

Fix: choose a matte finish, place the code on a flat surface where you can, and test it where it will actually be used.

9. It scans, but goes nowhere

Sometimes the code reads perfectly but the link is wrong: a typo, a page that was moved, or a file that was replaced. For Wi-Fi codes, a small difference in the network name or password stops the phone joining.

Fix: check the line under the preview, which shows exactly what your code holds, then open that link yourself. If you change the destination, make a new code.

Test before you print a batch

Scan a test print with two or three different phones, from the distance people will actually use, in the light it will actually be in. It takes a minute and saves a reprint.
