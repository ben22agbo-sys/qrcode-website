Spec sheet

Styled codes break when the rules are ignored. These are ours.

Every limit below comes from scanning test codes with two different decoders, including blurry, low-resolution copies made to look like a phone camera.

StandardISO/IEC 18004 QR Code Model 2, the format every phone camera reads.
SizesVersions 1 to 40, from 21×21 to 177×177 modules. The smallest size that fits your content is picked for you.
Error correctionLow 7%, Medium 15%, Quartile 25%, High 30%. The percentage is how much of the code can be lost and still read.
LogosUp to 25% of the code width. Adding a logo switches error correction to High, because lower levels failed in testing.
Colour contrastColour pairs below a 3:1 contrast ratio are blocked, so the code always stands out from its background.
Quiet zoneA clear border 4 modules wide on every side, as the standard asks. Scanners use it to find where the code starts.
TextFull UTF-8, so accents, other alphabets and emoji all work. Digits-only content is packed more tightly for a smaller code.
FilesSVG for print at any size, or a 1200 px PNG for screens and documents.

Questions

Before you print a thousand menus.

Is it really free?

Yes. Every feature is free, with no limit on how many codes you make and no watermark on them. There is no paid version and we never ask for card details.

Do I need an account?

You can make and style codes without one. To download, you need a free account. Sign in with Google or with a link sent to your email, so there is no password to remember.

Will my QR code ever stop working?

No. The content is stored inside the pattern itself, so there is no server or account that can expire. As long as the link it points to stays live, the code keeps working.

Can I change where the code points after printing?

Not with these codes. Because the content is inside the pattern, changing it means making a new code. If you might change the destination, point the code at a page on your own website that you can update later.

How small can I print it?

Keep it at least 2 cm wide for scanning up close. For scanning from further away, a common rule is that the code should be about one tenth of the scanning distance, so a poster read from 2 m needs a code around 20 cm wide. Shorter content makes a simpler code that prints smaller.

Is my information sent anywhere?

Your codes are made by your own browser, so your content and logo never leave your device. For your account, we only store your email address.

Why is error correction locked when I add a logo?

A logo covers part of the code, so the code needs spare data to rebuild what is hidden. High error correction gives the most spare data. In testing, lower levels started failing with larger logos.

Should I test the code before printing?

Yes, always. Scan the downloaded file with two or three different phones, ideally from the distance people will actually use, before sending anything to print.
